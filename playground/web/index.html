为什么没有 sqlite_query？（本地专属工具）
它读本机 sqlite 文件，边界是「只读 + 路径限制在 MCP_SQLITE_ROOT 内 + realpath 挡软链」。公网没有你的本机文件，放上来只能是假演示。本地跑 MCP 服务器即可用：node dist/index.js，宿主配 stdio。完整 8 工具与全部断言在仓库。
