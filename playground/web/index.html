MCP 工具 Playground

同一份 lib 纯函数源码的两个宿主：左边是 MCP stdio 服务器（任意 MCP 宿主即插即用），这里把它跑在 Qoder Sites 的 edge 函数上，浏览器直接调用。lib 层零 MCP 依赖、零 I/O（网页抓取除外），协议与业务解耦。

地点口碑榜 hotspot_rank

热度 = 发帖数×2 + 累计投票×3 + 平均评分×5，置顶优先。与 travel-rank 后端算法逐字一致。
点「排名」查看结果

JWT 解码 / 验签 jwt_decode

腾讯云 API 3.0 TC3-HMAC-SHA256。请用演示密钥，不要填真实密钥。

SQLite 只读查询 sqlite_query（本地专属）

这个工具不在公网版提供：它读本机 sqlite 文件，边界是「只读 + 路径限制在 MCP_SQLITE_ROOT 内 + realpath 挡软链」。公网没有你的本机文件，放上来只能是假演示。本地跑 MCP 服务器即可用：node dist/index.js，宿主配 stdio。完整 8 工具与 48 条断言在仓库。
